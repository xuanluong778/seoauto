Knowledge Base ⓘ

Một Knowledge Base dùng chung cho Content AI, Chatbot và toàn hệ thống

Knowledge Base & RAG

RAG (Retrieval-Augmented Generation) cho phép AI tra cứu dữ liệu nội bộ của bạn trước khi viết bài hoặc trả lời chatbot. Thay vì dựa vào kiến thức chung, AI sẽ tham khảo chính xác từ tài liệu bạn cung cấp — giúp nội dung đúng, đủ và nhất quán trên toàn hệ thống.

Quy trình hoạt động

Tạo Knowledge Base

Tạo KB cho dự án — nơi lưu trữ dữ liệu tham khảo riêng.

Import tài liệu

Dán văn bản, upload file (.txt, .md, .html) hoặc import hàng loạt từ CSV.

Tự động xử lý

Hệ thống cắt nhỏ (chunking) và tạo embedding vector cho từng đoạn.

AI viết bài với RAG

Khi viết bài, AI tra cứu KB để lấy thông tin chính xác, có nguồn dẫn.

Lợi ích khi dùng RAG

  • ✓ Bài viết chính xác hơn nhờ dữ liệu thực tế từ doanh nghiệp.
  • ✓ Giảm ảo giác AI (hallucination) — AI chỉ nói những gì có trong KB.
  • ✓ Thống nhất thông tin sản phẩm, giá cả, chính sách trên mọi bài viết.
  • ✓ Hỗ trợ nhiều định dạng: văn bản, Markdown, HTML, CSV.

💡 Gợi ý nội dung nên import

Thông tin sản phẩm / dịch vụ Báo cáo, nghiên cứu ngành FAQ, chính sách công ty Bài viết tham khảo chất lượng Dữ liệu kỹ thuật, thông số Nội dung đào tạo nội bộ

Nội dung càng chất lượng và có cấu trúc rõ ràng (tiêu đề, đoạn), AI càng tra cứu chính xác hơn.

WordPress ⓘ

Quản lý các website WordPress dùng để xuất bản bài.

How to connect Haravan
  1. Visit partners.haravan.com and sign in.
  2. Go to Apps → Create app and choose Private App for your store.
  3. In Scopes, enable web.read_contents and web.write_contents (blog / articles).
  4. Copy the Private Token from the app detail page.
Official REST blogs API uses Authorization: Bearer on apis.haravan.com. Docs also refer to com.read_contents / com.write_contents for the same content areas.
Seoauto SEO Helper Plugin Not Installed
Một số site WordPress chưa cài plugin Seoauto SEO Helper — plugin sẽ tự tối ưu SEO (OpenGraph, Schema, RankMath/Yoast sync) cho bài đăng từ Seoauto.
Cài đặt:
  1. Tải file plugin seoauto-seo-helper.zip.
  2. Vào WordPress Admin → Plugins → Add New → Upload Plugin.
  3. Chọn file zip rồi bấm Install Now → Activate.
